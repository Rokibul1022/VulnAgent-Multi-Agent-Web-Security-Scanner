# VulnAgent frontend

React 19 + Vite 8 dashboard for the VulnAgent scanner.

```bash
npm install
npm run dev     # dev server (defaults to :5173)
npm run build   # production build → dist/
```

The app calls the backend at `http://localhost:8000` (see `src/api.js`). For the full
project, architecture, and setup instructions, see the [root README](../README.md).
